# Project Overview

This repository contains a ticket bot built with Selenium for automating ticket creation and management.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Ensure you have ChromeDriver installed and accessible in your PATH.
3. Run the bot:
   ```bash
   python ticket_bot.py
   ```

## Usage

The bot logs into the ticketing system and creates tickets based on predefined templates.

## Requirements

- Python 3.10+
- Selenium
- Chrome/Chromium with matching ChromeDriver
